A loop is a conditional edge that goes back. We add a limit the docs leave out: after 3 attempts the loop stops anyway.

The evaluator
Part 1 · structured output again

A grade and the feedback

class Feedback(BaseModel): grade: Literal["pass", "fail"] = Field( description="pass only if every fact in the draft is in the notes, and every fact has its link") feedback: str = Field(description="If the draft fails, say exactly what to fix") evaluator = llm.with_structured_output(Feedback, method="json_schema", strict=True)

The rule lives in the description of grade. You test the evaluator on a bad and a good draft before you trust it.

The rule
The most important line

A rule the model can check

VagueCheckable
Be accurateEvery fact is in the notes
Use sourcesEvery fact has its link
Be shortEvery sentence has at most 20 words
A kind evaluator is uselessAsk for 'good quality' and it passes everything. Make the rule specific, so the evaluator can say exactly what is wrong.
The loop in code
Part 2 · two exits

A pass, or the limit

def write_draft(state: State): prompt = f"Answer ... Use only these notes: {state['notes']}" if state.get("feedback", ""): prompt = prompt + f"\nFix this problem: {state['feedback']}" msg = llm.invoke(prompt) return {"draft": msg.content, "attempts": state.get("attempts", 0) + 1} def route_draft(state: State): if state["grade"] == "pass" or state["attempts"] >= 3: return "Accepted" return "Rejected + Feedback" builder.add_conditional_edges("grade_draft", route_draft, {"Accepted": END, "Rejected + Feedback": "write_draft"})
