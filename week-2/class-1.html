Week 1 · An agent

The model decides

It chooses the next tool and when to stop. Flexible, but hard to predict and to test.

Week 2 · A workflow

You decide

You draw the steps. The model does one job in each step. Predictable, cheaper, easy to test.

The docs say it simplyWorkflows have fixed code paths. Agents choose their own. Most real systems mix the two: an agent can be one step of a workflow.

Chaining with LangChain
Part 2A · LangChain: the pipe

Three parts, one pipe

write_prompt = ChatPromptTemplate.from_template("Answer this question: {question}") shorten_prompt = ChatPromptTemplate.from_template("Shorten this to at most 3 sentences: {answer}") write_step = write_prompt | llm | StrOutputParser() # prompt -> model -> text shorten_step = shorten_prompt | llm | StrOutputParser() def check_and_shorten(answer): # the gate: plain Python if len(answer.split()) > 80: return shorten_step.invoke({"answer": answer}) return answer lc_chain = write_step | check_and_shorten lc_chain.invoke({"question": "Explain how the internet works."})

a | b: the output of a goes into b. A prompt with a {placeholder}, the model, and a parser that keeps only the text. A plain Python function in the pipe becomes a step: here, the gate.

Chaining with LangGraph
Part 2B · the same chain as a graph

State, node, edge, gate

def check_length(state: ChainState): # the gate: plain Python if len(state["answer"].split()) > 80: return "Fail" return "Pass" builder = StateGraph(ChainState) builder.add_node("write_answer", write_answer) builder.add_node("shorten", shorten) builder.add_edge(START, "write_answer") builder.add_conditional_edges("write_answer", check_length, {"Fail": "shorten", "Pass": END}) builder.add_edge("shorten", END) chain = builder.compile()

LangChain or LangGraph?
The same chain, two tools

A line, or a graph?

LangChain pipe |LangGraph
Steps in a straight lineshortest codeworks, more code
A gate (if)hidden inside a functiona visible conditional edge
See each step's resultonly the final textthe state keeps every key
Parallel, workers, loopshardbuilt in (Days 2 and 3)
The ruleSteps in a line: the LangChain pipe. A decision, parallel work or a loop: LangGraph. A LangGraph node can run a pipe inside it.

First route. Then measure.

def route_question(state: RouterState): return {"decision": router.invoke(state["question"]).step} def answer_search(state: RouterState): result = search_agent.invoke({"messages": state["question"]}) return {"answer": result["messages"][-1].content} def route_decision(state: RouterState): if state["decision"] == "search": return "answer_search" return "answer_direct" builder.add_conditional_edges("route_question", route_decision, {"answer_search": "answer_search", "answer_direct": "answer_direct"})
