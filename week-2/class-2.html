Orchestrator-worker
Part 2 · the steps are not known in advance

One plan, many workers

The plan decides how many workers run, at run time. Each worker does one search and one model call.

Send and a reducer
Two LangGraph blocks

Send starts workers. A reducer joins notes.

class State(TypedDict): question: str steps: list[str] notes: Annotated[list, operator.add] # a reducer: workers ADD notes brief: str def assign_workers(state: State): workers = [] for step in state["steps"]: workers.append(Send("research_step", {"step": step})) return workers builder.add_conditional_edges("make_plan", assign_workers, ["research_step"])
Send

One worker for each step

Send(node, input) starts one copy of a node with its own small input.

operator.add

Add, not replace

Without it, each worker would overwrite the last note.

Parallel is fast. The free plan is small.
