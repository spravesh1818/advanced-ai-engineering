Part 2 · Tool
Part 2 · One tool

Inside search_web

@tool def search_web(query: str) -> str: """Search the web and return the top results...""" results = None for attempt in range(2): try: results = DDGS().text(query, max_results=3) break except Exception: time.sleep(2) if results is None: return "Error: the search failed. ..." if len(results) == 0: return "Error: nothing found for " + query lines = [] for result in results: lines.append(result["title"] + ": " + result["body"][:300] + " (" + result["href"] + ")") return "\n".join(lines)
1
Ask DuckDuckGo for 3 results
2
Free search can say "slow down": try twice
3
Failed or empty? Return an Error: text
4
Else: one line per result: title, summary, link
Questions that may come up0:34 to 0:40
What does [:300] mean?
Take only the first 300 characters of the summary, so the text we give the model stays short.
Why try twice?
The free search sometimes refuses a request for a moment. Waiting 2 seconds and trying again usually works.
Why return text and not raise an error?
A returned message goes back to the model, which can read it and react. An exception would stop everything.
What is DDGS?
A small library that asks DuckDuckGo for search results. It needs no key.
What does join do?
It glues the list of lines into one text, with a new line between each result.

Yes, for this question. But the next question may need three searches, or none. We cannot write a step for every case.
So is a workflow bad?

Keep it bounded

Step limit

recursion_limit=10

The agent stops after 10 steps, so it can never run forever.

Retry

Try twice

Inside the tool: wait 2 seconds and try again when the search says slow down.

Safe errors

Error: text

A failing tool returns a message. The model reads it. The cell does not crash.

WhyA bounded loop is what makes an agent safe to run and cheap enough for a free key.
Questions that may come up1:15 to 1:17
What counts as a step?
Each trip between the model and the tools. One search question uses about three steps: model, tool, model.
What if the limit is too low?
The agent stops before it answers and prints Stopped early. Raise it a little.
What is a bounded loop?
A loop with a clear stop: a step limit, a time limit, or both.
Part 5 · Memory
Part 5 · Agent memory

Same thread, same memory

agent = create_agent(llm, tools=[search_web], system_prompt=system_prompt, checkpointer=InMemorySaver()) config = {"configurable": {"thread_id": "class-1"}, "recursion_limit": 10}
Questions that may come up1:17 to 1:21
What does thread_id do?
It names the conversation. The saver stores the messages under that name, so the same name brings the same memory back.
What is InMemorySaver?
A saver that keeps the messages in the computer's memory while the notebook runs. Restart the notebook and it is gone.
What is in config?
Settings for one run. recursion_limit is a LangChain setting. thread_id sits inside configurable, which LangGraph's saver reads.
Does memory cost anything?
Yes. The old messages are sent again each turn, so longer chats use more tokens.
